# Izabella Lapierre — personal website

My project website for RESECON 490AI (Fall 2026): Home, About, Projects, Résumé, Contact.

## How to open it
Double-click `index.html` in File Explorer. It opens in your browser. Use the tabs at the top to move between pages.

## How to publish it (GitHub Pages)
Upload everything inside this `site` folder (not the folder itself) to the repository
`izaelapierre-code.github.io` on github.com. After 1–2 minutes it is live at
https://izaelapierre-code.github.io

## Files
- `index.html` Home · `about.html` · `projects.html` · `resume.html` · `contact.html`
- `styles.css` all colors, fonts and layout (colors are at the top)
- `photo.jpg` my photo (a copy; the original is in the 490AI folder)
- `NOTES.md` design decisions and a dated list of changes
